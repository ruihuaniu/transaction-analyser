# Transaction Analyzer

A local React app for uploading bank statement CSV/XLSX files and analysing transactions.

## Run locally

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open the URL shown in the terminal.

## Notes

- The app entry is `index.html`.
- The UI component is in `transaction-analyzer.jsx`.
- Upload a `.csv`, `.xlsx`, or `.xls` file to analyse your transactions.
